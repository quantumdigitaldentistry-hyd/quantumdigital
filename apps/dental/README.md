# dental (Expo app)

The single Expo app that ships to **web, Android (.apk) and iOS (.ipa)**.
See the [root README](../../README.md) for setup and commands.

- Routes: `src/app/` (Expo Router — every file is a screen)
- Styling: Tailwind classes via Uniwind, theme in `src/global.css`
- Supabase client: `src/lib/supabase.ts` (env in `.env`, see `.env.example`)
- Build profiles: `eas.json`
